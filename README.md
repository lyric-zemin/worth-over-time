# 时间小票 · 陪伴账本

一款移动端优先的记账小应用：记下商品名称、价格和购买日期，它会自动配上有趣的图标，算出这件东西**已经陪了你多少天**、**平均每天花多少钱**。每次再打开，数字会从上次查看时的值滚动到今天的值——时间越久，小票越便宜。东西坏了、丢了或送人之后，还能给它盖上失效章，把那天的数字永久定格。

基于 Next.js 15 App Router + shadcn/ui + Tailwind CSS，纯前端、无账号、无服务器。

## 本地运行

需要 Node.js 20 及以上。

```powershell
npm install
npm run dev
```

打开 <http://localhost:3000>。其他命令：

## 功能说明

- **记一笔**：名称、金额（精确到分）、购买日期；名称自动匹配离线图标规则，可手动更换，也可上传本机图片（自动裁方、压缩后存在本地）。
- **时间小票**：`已购天数 = 日历天数差 + 1`（当天算第 1 天），`日均成本 = 四舍五入(价格分 / 已购天数)`。金额以整数「分」存储，无浮点误差。
- **失效与定格**：详见下一节。盖章后天数与日均成本固化，不再变化。
- **上次查看的变化**：保存上次快照，再次打开时滚动展示间隔天数与日均成本降幅（仅有效小票）。首次打开建基线，同日重复打开提示「与上次一致」。
- **回顾**：累计陪伴天数、日均成本排行与分类占比，只算有效小票。
- **外观**：浅色 / 深色 / 跟随系统，外加暖橘、暮紫、薄荷、麦芽四套配色。
- **数据**：存于浏览器 `localStorage`，支持 JSON 全量备份、CSV 导出，以及「合并追加 / 覆盖恢复」导入，清空前有二次确认。
- **交互**：撕边小票与日戳质感、上滑抽屉、侧滑撕下并可撤销、盖章动效、轻震动反馈，支持系统的「减弱动效」偏好。

> 换浏览器、换设备或清理浏览器数据前，记得先导出 JSON 备份。

## 失效与定格

在有效小票的详情里点「标记失效」：

1. **失效日期**：默认今天，可回溯到「购买日 ~ 今天」之间的任意一天，日历会自动挡住范围外的日期。
2. **失效原因**：必填，提供「坏了 / 丢了 / 卖掉 / 退掉 / 送人」快捷标签，填入后仍可继续编辑（最多 60 字）。
3. **盖章瞬间计算并写入**：`共陪伴天数 = 失效日 - 购买日 + 1`，`定格日均 = 四舍五入(价格分 / 共陪伴天数)`，确认后固化、不再变化，并记录操作时间（到分钟）。

失效之后：

- 这张小票从**总投入、每天合计、件数、回顾排行与分类占比、变化动画**中剔除；主列表只显示有效小票。
- 收进「已失效 · 归档」区（保持排序）；纸面褪色、图标去饱和、斜盖印章，卡片直接显示原因、时间与定格值。
- 归档区可一键收起 / 展开，设置页也有同一开关，偏好会记住。
- 详情里可**一键恢复有效**：清空失效信息，重新按原购买日计算。误标可撤销，撕下归档小票后撤销也会带回失效状态。

数据兼容：失效原因、`expiredOn`（日历日）、`expiredAt`（时间戳）与定格值随 JSON 导出；旧数据缺字段时按有效小票处理。CSV 为**查阅型**：导出追加状态/失效信息列，导入只取名称、价格、日期构造有效小票，完整恢复请用 JSON。

```
src/types        共享数据类型

```
